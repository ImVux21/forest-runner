# Free Game Assets Resource Guide (Kenney Alternatives & Complements)

A curated reference of free, CC0, and royalty-free game development resources (2D, 3D, Audio, UI, and Tools) formatted for automated harnesses, reference parsers, and game development workflows.

---

## 1. Multi-Disciplinary Repositories (2D, 3D, Audio, UI)

| Resource | Primary URL | License Type | Description & Highlights |
| :--- | :--- | :--- | :--- |
| **Kenney** | `https://kenney.nl/assets` | **CC0 (Public Domain)** | Standard-setting modular assets across 2D sprites, 3D low-poly models, audio SFX, UI sheets, and in-browser prototyping tools. |
| **OpenGameArt** | `https://opengameart.org/` | Mixed (CC0, CC-BY, GPL) | Massive community-driven archive for pixel art, tilesets, 3D props, background loops, and sound effects. Filter by license required. |
| **Itch.io Free Assets** | `https://itch.io/game-assets/free` | Mixed / Creator Discretion | Indie developer and artist storefront. Rich in modern pixel art, UI themes, platformer kits, and experimental game toolkits. |
| **Game-Icons.net** | `https://game-icons.net/` | **CC-BY 3.0** | Over 4,000 vector icons (SVG/PNG) customized for inventory, skill trees, cards, and UI elements. |

## Quick License Reference for Automated Ingestion

```text
CC0 (Creative Commons Zero):
- Attribution: Not required (recommended as good practice)
- Commercial Use: Allowed
- Modification: Allowed

CC-BY (Attribution):
- Attribution: Mandatory in credits or documentation
- Commercial Use: Allowed
- Modification: Allowed

Royalty-Free / Store EULA:
- Attribution: Check individual pack terms
- Redistribution: Raw files cannot be resold as standalone assets
- Usage: Allowed within compiled game binaries
```
